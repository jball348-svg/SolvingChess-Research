# 8. New G7 proof-language axis: strategy-language composition
G7.FILTERED_ATTRACTOR retains the original game graph but adds a semantic predicate F on attacker edges. Attr_F(T) certifies that the attacker can force target T while every pre-target attacker move is F-admissible; defender semantics and terminal/capture typing remain unchanged. CHECK is the first frozen instantiation.

The deeper new theorem is FILTER_PIVOT. Let A=Attr(T), C=Attr_F(T), and Q=A\C. Define K_F as attacker-owned states in Q with an F-excluded edge into C. Then Q is nonempty iff K_F is nonempty, and Q equals the ordinary residual backward closure of K_F outside C. The theorem follows because defender admission is unchanged by the attacker-edge filter: the first newly admitted state outside C cannot be defender-owned, so it must be an attacker state entering C through an excluded edge.
