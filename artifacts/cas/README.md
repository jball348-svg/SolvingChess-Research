# CAS placeholder

This directory exists only so migration-era tooling has a documented location for future
content-addressed artifacts.

It is deliberately empty of proof-store policy.

Its existence does not:

- begin or implement G14;
- choose object, dependency, chunking or retention semantics;
- supersede G12 or G13 identity contracts;
- authorize unregistered large-object storage;
- establish a proof-store result.

Until G14 legitimately executes and freezes a policy, inherited originals remain in their
migration locations, large objects require explicit registry entries, and unregistered
deletion or identity-changing reserialization is forbidden.
