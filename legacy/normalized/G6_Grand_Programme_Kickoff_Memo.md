# G6 Grand Programme Kickoff Memo
From local finite arenas to a sustained proof-system research programme
NEXT PROJECT — AN INTENTIONALLY WIDE, LONG-RUN SESSION: BUILD, STRESS, COMPOSE, GENERALIZE, AND TRY TO BREAK THE EMERGING PROOF LANGUAGE ACROSS A PORTFOLIO OF CHESS TOPOLOGIES.
Frozen research handoff generated from the G5 prospective-transfer benchmark session.
11 August 2026
# Mission
G6 should be intentionally much larger than G5. It is not “one more arena” and not a narrow attempt to recover the two operations that failed prospectively. It should function as a substantial research season: build a reusable exact finite-game laboratory, run a portfolio of materially different arenas, develop a typed library of proof objects, test transfer at multiple scales, investigate why operations succeed or fail, and finish with a cross-arena theory of where symbolic compression in chess appears to come from.
The programme should be allowed to consume a long interactive session and many sequential experimental passes. It should contain multiple independent workstreams with explicit internal gates, negative-result preservation, and periodic freezes. The goal is not to maximize one headline percentage. The goal is to leave G6 with a materially stronger scientific object: a reusable proof-system prototype plus a benchmark corpus large enough to distinguish universal operations, conditional operations, topology-specific mechanisms, and irreducible local singularities.
# 1. Starting evidence
Pilot 1 established hierarchical compression, exact race surfaces and local diagonal grammar, while exposing mobile-king fragmentation. Pilot 2 and G3 established lower-material inheritance, semantic cooperative targets, strict reachability and a genuine predicate-union return bridge, followed by a local lookup-scale floor. G4 transferred much of that architecture to a three-pawn race and localized 97.67% of the unresolved WK-sensitive frontier to a one-move three-clock slab before another local complexity floor. G5 then imposed prospective discipline across knight and bishop topologies. It found the same exact semantic target and strong strict attractors in both, plus 99.03% / 96.06% critical-manifold localization, but it falsified universal compact restoration and found zero pure union-bridge increment. The final tails again crossed the predeclared description-cost threshold.
The central lesson entering G6 is therefore not “the language works” or “the language fails.” Different operations have different transfer domains. G6 should discover those domains.
# 2. North-star questions
- Can the successful operations be promoted from ad-hoc predicates into typed, machine-checkable proof objects with explicit preconditions and composition rules?
- Can we learn when PROJECT/INHERITS is expected to be monotone, when restoration interference is likely, and whether failure families themselves admit reusable semantic classification?
- What structural conditions make union BRIDGE genuinely stronger than separate target attractors?
- Do critical manifolds remain low-dimensional as material, mobility and tactical branching increase?
- Can a common vocabulary cover pawn races, sliders, leapers, opposite-colour geometry, capture transitions and mixed material without hidden square identifiers?
- Can proof search choose useful abstractions automatically while retaining exhaustive certification?
- At what scale does description cost stop growing sublinearly relative to exact state count?
- Can the system predict in advance that a residual is likely to hit a lookup-scale floor and stop wasting search?
- Can multiple exact local lemmas be composed into materially larger solved regions than any individual arena-specific rule?
- What is the smallest credible path from these finite experiments toward a general endgame proof architecture rather than a collection of micro-tablebases?

# 4. Workstream A — Generic exact-game laboratory
Before large-scale inference, turn the accumulated solvers into a common research harness. This is a major G6 deliverable in its own right, not setup overhead.
- Typed state schemas and material signatures.
- Pluggable legal-move generators and terminal semantics.
- Exact attractor / retrograde engine supporting W/D/L and rank histograms.
- Projection maps into lower-material subgames.
- Strict target-attractor and union-attractor operators.
- Symmetry canonicalization and GROUP_OUT abstractions.
- Deterministic bitsets, hashes, residual tables and counterexample logs.
- Independent move-generation cross-check mode.
- Experiment manifests that freeze arena restrictions and feature vocabularies before solving.
- Automatic superseded-result ledger when a regression changes truth.
# 5. Workstream B — Typed proof-object library
Replace the informal operation names with explicit proof-object contracts. Every promoted object should carry domain, predicate, truth direction, exception family, dependencies, certificate hash and composition semantics.
| Object | Required semantics |
| --- | --- |
| Projection theorem | Map full state to exact lower-material truth; state what restoration preserves and under what preconditions. |
| Direct predicate theorem | Zero-counterexample implication or biconditional on an explicit domain. |
| Strict reachability theorem | Exists/forall attractor to an explicit target with declared shortcut semantics. |
| Union-return theorem | Certificate that union reachability adds states beyond constituent attractors, with pure-bridge count. |
| Localization theorem | Necessary containment of a residual frontier in a declared manifold/slab. |
| Grammar theorem | Exact local predicate with description-cost accounting. |
| Complexity-floor certificate | Evidence that bounded exact representation reaches the predeclared lookup threshold. |
| Falsification certificate | Counterexample family sufficient to reject a proposed reusable law. |
# 6. Workstream C — Restoration and interference theory
G5 showed that adding a friendly minor can spoil a KPK win for reasons beyond stalemate. G6 should treat this as a research topic rather than an inconvenience.
- Partition restoration failures by mechanism: self-blocking, loss of stalemate resource, checking geometry, forced capture, tempo loss, king-access obstruction, zugzwang, promotion-square interference, or other exact semantic families.
- Compare knight, bishop and rook restoration under matched pawn/king geometries.
- Test whether monotonicity can be recovered under semantic preconditions such as “added piece is outside the king/pawn access cone” or “added piece has a legal neutralizing move.”
- Search for one-way safe-restoration theorems rather than full monotonicity.
- Measure exception-family description length and stop if it degenerates into square catalogues.
- Build a restoration-risk predictor only as a discovery tool; every promoted rule remains exhaustively scanned.
# 7. Workstream D — When does BRIDGE exist?
G3/G4 found substantial pure union-return effects; G5 found none. G6 should identify the structural condition behind that difference.
- Construct target pairs with deliberately different adversarial escape profiles, but choose the target grammar prospectively rather than fitting square sets.
- Measure overlap, separate attractor basins, frontier adjacency and whether the defender can choose which target is entered.
- Define and test “complementary target” metrics before solving pure-bridge truth.
- Search for minimal examples where union reachability is strictly stronger than either constituent reachability.
- Test three-way and hierarchical unions only after two-way bridge mechanics are understood.
- Distinguish bridge as a mathematical composition operation from merely taking the union of already-large attractors.
# 8. Workstream E — Critical-manifold atlas
This should be one of the largest G6 workstreams. Build an atlas of where mixed exact truth concentrates after robust interiors are removed.
- Promotion-race equalities and parity-adjusted near-ties.
- King interception to current piece fronts.
- Moving-path rendezvous surfaces.
- Slider line-entry and line-blocking times.
- Knight access parity / graph-distance ties.
- Checking-distance and tempo surfaces for rook-like pieces.
- Capture-race surfaces between competing material transitions.
- Colour-complex corridor distances.
- Support/contact onset surfaces.
- Multi-resource intersections and codimension estimates.
For each arena, measure exact-surface coverage, one-ply and one-move slab coverage, off-surface tail size, and whether widening the slab is scientifically meaningful or merely absorbing the whole space. Track codimension and description cost, not just percentages.
# 9. Workstream F — Automatic symbolic discovery under proof discipline
G6 should permit substantially more automated search than previous stages, but with a hard separation between discovery and certification. Search may use decision trees, rule learners, SAT/SMT-style template enumeration, integer inequalities, feature conjunction mining or small program synthesis. None of these are proof by themselves.
- Generate candidates only from a versioned frozen atom library plus explicitly declared parameterized templates.
- Rank candidates by certified coverage per description-cost unit.
- Immediately flatten candidates to explicit predicates and exhaustively scan the stated domain.
- Retain counterexamples as first-class artifacts.
- Penalize absolute square IDs and one-off constants unless they arise from a reusable coordinate system.
- Run held-out-arena prospective evaluation: discover on one subset, freeze, then evaluate unchanged on another.
# 10. Workstream G — Scaling experiment
Choose at least one topology and create a nested sequence of arena sizes. The point is to measure scaling laws rather than solve the largest possible table.
- Increase pawn rank bands, minor mobility regions or allowed files in predeclared steps.
- Record raw states, static-valid states, solve time/memory, proof coverage, residual geometry count, manifold coverage and grammar AST size at every scale.
- Fit descriptive growth curves only after all exact counts are frozen.
- Ask whether proof description grows sublinearly, linearly or superlinearly with solved state count and with residual geometry count.
- Identify phase transitions where a previously compact mechanism fragments.
# 11. Workstream H — Cross-arena theorem mining
After several arenas are frozen, search for statements whose domains quantify over material/topology classes rather than one arena. Examples include conditional restoration laws, generic race/interception localization, target-strength lower bounds, or criteria for pure union bridges. This is the point where G6 should begin turning empirical finite results into candidate general theory.
# 12. Workstream I — Proof graph and composition engine
Represent certified predicates and transitions as a proof graph. Nodes are exact regions or lower-material truth sets; edges are operations such as projection, restoration implication, strict reachability or bridge. Then ask whether automated composition can derive new certified regions without rerunning unrestricted symbolic search.
- Track dependency DAGs so every certified state can be traced to base truth and operations.
- Compute marginal coverage of each proof object.
- Detect redundant lemmas and subsumption.
- Search bounded sequences of operations, e.g. PROJECT → TARGET → ATTRACTOR → BRIDGE → PROJECT.
- Measure whether proof-graph depth increases coverage economically or merely duplicates tablebase search.
- Emit human-readable proof sketches from the dependency graph alongside machine certificates.
# 13. Workstream J — Negative controls and adversarial falsification
A long G6 season should spend meaningful effort trying to break its own language. Predeclare at least two arenas expected to be hostile to compression: high local mobility, many checking moves, or competing capture transitions. Success means an honest complexity-floor certificate if compression fails.

# 16. Advance criteria
- At least six materially/topologically distinct prospective arenas or arena families receive exact certified passes, including at least one rook-like topology and at least one opposing-minor topology if tractable.
- A generic harness reproduces the frozen historical checksums and emits deterministic certificates.
- At least three proof-object types transfer prospectively across three or more topology families.
- A conditional theory of restoration is materially better than raw exception cataloguing—or restoration is frozen as fundamentally topology-local under the tested language.
- The programme explains at least one sufficient structural condition for a nonzero pure union bridge, demonstrated prospectively.
- Critical-manifold localization remains strong in multiple new topologies, or its failure domain is sharply characterized.
- At least one held-out-arena symbolic discovery test succeeds without vocabulary retuning.
- At least one nested scaling family shows how description cost changes with arena size.
- A proof graph composes multiple certified objects into a region materially larger than any single object, with traceable certificates.
- At least two adversarial negative controls are preserved honestly.
- The final synthesis identifies universal, conditional and local operations rather than treating the library as uniformly reusable.
# 17. Failure criteria
- Most useful predicates require arena-specific absolute-square atoms.
- Certificate/harness discrepancies remain unresolved across historical baselines.
- Critical manifolds become high-dimensional immediately outside pawn-heavy arenas.
- Automated discovery gains coverage only by increasing description cost near linearly with state count.
- Bridge phenomena cannot be predicted better than post-hoc target search.
- Restoration failure families resist any reusable semantic partition and dominate projected regions.
- Proof-graph composition adds negligible coverage beyond direct attractor solves.
- Scaling experiments show proof description growing approximately as fast as exact residual enumeration before any reusable layer emerges.
- Prospective held-out performance collapses while retrospective fits remain strong.
# 18. Stopping rules
G6 is intentionally long, but it should not become endless. Stop an individual local grammar at the same lookup-scale threshold unless a parameterized reusable family appears. Stop a workstream when two successive prospective arenas produce the same negative mechanism with no reduction in description cost. Stop scaling when the next arena exceeds the certificate budget without changing the scientific question. Do not stop the whole G6 season merely because one arena fails; the programme is explicitly a portfolio.
# 19. Ambitious end-state
A successful G6 should end with more than another technical report. The desired end-state is a small research platform and a theory map: a reproducible exact-game harness; a corpus of solved prospective arenas; a typed proof-object library; a critical-manifold atlas; restoration and bridge mechanism studies; scaling evidence; a proof dependency graph; and a clear classification of which symbolic operations are universal, conditional, topology-specific or locally intractable.
The strongest possible G6 result would be a demonstration that exact chess regions can be built compositionally from a modest reusable library whose description cost grows much more slowly than the exact state spaces across several movement topologies. The equally valuable negative would be a precise boundary showing that this ceases to hold once mobility, checking or capture topology crosses identifiable thresholds.
