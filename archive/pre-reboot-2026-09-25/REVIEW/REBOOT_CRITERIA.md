# Continue / reboot / stop criteria

This file fixes decision criteria before the decisive audit work.

## CONTINUE_CURRENT_ROADMAP

Use only if the review can name a concrete mechanism already supported by evidence that makes G15-G42 a defensible experiment rather than a list of hoped-for capabilities.

At minimum, identify one of:

- a repeatable lifting/composition theorem;
- a stable multi-ascent scaling law on materially less restricted domains;
- a start-reachable all-replies expansion mechanism.

Closing the current G13 replay blocker alone is insufficient.

## REBOOT

Use if substantial assets remain valuable but the sequential G roadmap is poorly coupled to the central proof risk.

A reboot must:

- preserve frozen results and negative evidence;
- stop using G-count as the unit of progress;
- make the Chess Bridge Problem primary;
- use short bounded sessions with one falsifiable bridge/scaling claim each;
- attack the claim before supportive local computation;
- maintain an append-only ledger and explicit demotions;
- forbid disconnected scale/infrastructure work unless it retires a named bridge obligation;
- define a hard budget after which failure to find a surviving bridge stops the method.

### Suggested bounded survival trial

At most six bridge sessions unless the user explicitly changes the budget.

Each session must:
1. State one precise Bridge Theorem or scaling proposition.
2. State which current results it would connect.
3. Attempt falsification with a countermodel, hostile arena, lower-bound argument or scaling test.
4. Record what survived and which obligation was retired.
5. Take a strike if it produces only another local result, cannot state a falsifiable bridge, or reports progress without retiring an obligation.

Three strikes force a stop-current-method verdict at the next session. Budget exhaustion without decisive evidence yields `INCONCLUSIVE` unless the evidence independently supports `STOP_CURRENT_METHOD`.

### Survival events that count

- A genuine lifting result deriving a materially larger/higher-tree exact region without first solving essentially all of it state-by-state.
- A materially unrestricted higher-piece/topology result with a measured scaling law surviving more than one ascent and retaining acceptable verification economics.
- A genuinely `START_REACHABLE` all-replies certificate whose frontier expands by a repeatable certified mechanism.

Certificate-byte reduction alone does not count. Another highly restricted fixed-geometry arena does not count. Faster enumeration of another disconnected island does not count. Infrastructure hardening alone does not count.

## STOP_CURRENT_METHOD

Use if the strongest bridge candidates repeatedly collapse into raw enumeration, restate the target theorem, or are broken by structural counterexamples/scaling barriers with no materially different candidate remaining.

This preserves valid restricted chess results; it says the present method is not a credible route to the global objective.

## INCONCLUSIVE

Use when the audit cannot responsibly distinguish reboot from stop. Name the smallest discriminating theorem attack or experiment and a strict resource budget. No large sequential programme resumes merely because the review is inconclusive.
