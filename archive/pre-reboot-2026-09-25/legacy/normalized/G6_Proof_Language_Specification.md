# G6 Proof Language Specification
*Typed finite-game proof objects, domains, certificates and composition semantics*
FROZEN SPECIFICATION v1.0 — ACCOMPANIES G6 FINAL CLOSEOUT
11 August 2026
Specification extracted from the G6 cross-arena synthesis; independent of any single arena.
This document defines the proof-system object model established by G6. It is intentionally stricter than an informal chess heuristic library: every promoted object declares its game model, state domain, truth direction, dependencies, exception family, certificate semantics and composition rules.
# 1. Common proof-object envelope
| Field | Required meaning |
| --- | --- |
| object_id | Stable identifier and version. |
| object_type | Projection, direct predicate, strict attractor, restoration theorem, branch/hyperkernel, sanctuary, localization, grammar, complexity floor, falsification, or supersession. |
| game_model | Material schema, legal-move rules, static/historical reachability convention, terminal semantics, omitted state such as repetition/en-passant counters. |
| domain | Explicit finite set/predicate on which the claim is asserted. |
| truth_direction | White-win, Black-win, draw/non-loss, implication, biconditional, or reachability objective. |
| predicate / operator | Machine-flattenable exact statement. |
| dependencies | Hashes/IDs of lower-material truth sets or prior proof objects. |
| exception_family | Explicit semantic family or empty; never an implicit square catalogue. |
| certificate | Universe count, hit count, counterexample count, deterministic hash, solver/version and rank convention where relevant. |
| composition_semantics | How the object may be used by later proof graph nodes. |
| status | Universal theorem / conditional theorem / certified finite fact / compression observation / falsification / superseded / historical exception. |
| Mandatory model principle<br>Terminal semantics and rank semantics are part of the certificate contract. Changing terminal semantics changes the game graph and requires re-certification. Rank labels must never be compared across solvers without an explicit rank convention. |

# 2. Core object types
| Object | Contract |
| --- | --- |
| Projection theorem / fact | Maps a full state to exact lower-material truth. Projection alone does not imply restoration monotonicity. |
| Restoration theorem | Finite implication from projected truth to restored truth under explicit semantic guards; every exception must be exhaustively enumerated and semantically classified. |
| Direct predicate theorem | Zero-counterexample implication or biconditional on an explicit domain. A learned rule is not promoted until flattened and exhaustively scanned. |
| Strict reachability theorem | Exact attacker-existential / defender-universal attractor to a declared target. Promotion/capture/material-reduction shortcuts are failures unless explicitly included in the target contract. |
| Defender sanctuary attractor | Role-dual strict attractor certifying draw/non-loss by forced entry into a trusted sanctuary. |
| Branch-kernel theorem | For two constituent attractors, defines the necessary-and-sufficient defender kernel for strict pure union BRIDGE and generates the full pure region by residual backward closure. |
| Hyperkernel theorem | n-way generalization: irreducible full-union reachability beyond every proper subunion is generated by defender hyperkernel states plus residual backward closure. |
| Localization theorem / observation | Necessary containment or measured concentration of a residual frontier in declared semantic surfaces. Must report localization lift, not only mixed coverage. |
| Grammar theorem | Exact finite predicate over a bounded semantic DSL with explicit AST/leaf cost and zero counterexamples. |
| Complexity-floor certificate | Evidence that bounded exact description approaches lookup scale; triggers STOP rather than absolute-square patching. |
| Falsification certificate | Counterexample set sufficient to reject a proposed reusable law. |
| Supersession certificate | Explicitly invalidates an earlier result after a model or implementation correction; downstream artifacts name the replacement. |
# 3. Strict attractor operator
Given target T and a fixed game graph, initialize A0=T. Repeatedly add attacker-owned states with at least one legal successor in A, and defender-owned states with at least one legal move and every legal successor in A, respecting the target’s declared shortcut semantics. The least fixed point is Attr(T). Terminal states enter only according to the object’s terminal contract.
# 4. Branch-Kernel composition contract
Inputs: certified constituent attractors A1=Attr(T1) and A2=Attr(T2) under identical game/shortcut semantics. Define B=A1∪A2. A branch-kernel state k is defender-owned, k∉B, all legal successors are in B, and the successor set is not contained wholly in A1 or wholly in A2. The strict pure bridge is the residual backward closure of K through states outside B using the usual attacker-existential / defender-universal predecessor rule.
- Nonempty K is necessary and sufficient for nonempty strict pure BRIDGE.
- If A1⊆A2 or A2⊆A1, pure BRIDGE is empty.
- The branch-kernel object depends only on already-certified constituent basins plus the game graph; it does not require a fresh symbolic predicate search.
# 5. Hyperkernel composition contract
For targets {Ti}, first compute/certify attractors for relevant proper target subunions. Let B be the union of maximal proper-subunion attractors. The irreducible n-way kernel contains defender states outside B whose replies all enter B but are not contained in any one maximal proper-subunion attractor. Residual backward closure yields the irreducible n-way region.
# 6. Resource-safe TARGET constructor
| Constructor<br>CORE_TARGET ∧ TERMINAL_SAFE ∧ CONVERSION_PATH_AVAILABLE ∧ OPPONENT_RACE_NONDOMINANT ∧ OPPONENT_ACCESS_OUTSIDE_RELEVANT_CONE |
| --- |
This is a schema rather than a universal theorem. A target instantiation activates only guards for resources present in the arena and must be prospectively frozen before its held-out evaluation. Absolute-square repair clauses are not a transfer success unless they arise from a reusable coordinate system.
# 7. Restoration contract
PROJECT supplies exact lower-material information. INHERITS is a separate implication requiring certification. The G6 examples FAR5/FAR3 demonstrate the intended form: a projected win plus semantic distance/terminal guards yields restored truth on a declared domain; if a finite exception family exists, it becomes part of the theorem rather than being hidden.
# 8. Localization contract
- Freeze feature clocks/manifolds before outcome-guided local fitting.
- Report mixed-frontier coverage and all-residual coverage for the same slab.
- Report localization lift = mixed coverage − all-residual coverage.
- A high raw percentage with near-zero lift is not evidence of a selective critical manifold.
- Only after the manifold audit may a bounded local grammar be fitted.
# 9. Grammar and STOP contract
A learned tree/program is discovery machinery only. The promoted object is the flattened exact predicate plus a zero-counterexample scan and description-cost measure. If exact leaf/AST cost approaches the predeclared lookup threshold without a reusable parameterized family, emit a complexity-floor certificate and stop.
# 10. Proof graph
Nodes are exact regions/predicates with object IDs and hashes. Edges are typed operations: PROJECT, RESTORE/INHERITS, TARGET→ATTRACTOR, BRANCH/HYPERKERNEL composition, defender sanctuary attraction, residualization, localization and grammar. Every certified state should be traceable through the dependency DAG to exact base truth and terminal/model declarations.
| Proof-graph metric | Purpose |
| --- | --- |
| Marginal coverage | States newly certified by one object beyond dependencies. |
| Cumulative coverage | Total certified basin under the DAG. |
| Kernel amplification | Pure compositional region divided by kernel size. |
| Depth | Number of typed composition steps from base truth. |
| Subsumption/redundancy | Detect lemmas that add no new states or are contained by stronger objects. |
| Certificate size / description cost | Test whether proof representation grows slower than raw exact truth. |
# 11. Status taxonomy
| Status | Meaning |
| --- | --- |
| UNIVERSAL / MATHEMATICAL | Proved for the stated finite-game graph class; chess topology is not part of the theorem. |
| CONDITIONAL FINITE THEOREM | Exhaustively exact on an explicit finite chess domain with semantic preconditions. |
| CERTIFIED FINITE FACT | Exact count/membership without a compact general theorem. |
| COMPRESSION OBSERVATION | Exact/near-exact representation result whose particular tree/grammar is not mathematically unique. |
| FALSIFICATION | Counterexamples reject a proposed stronger rule. |
| COMPLEXITY FLOOR | STOP certificate under a predeclared DSL/description-cost convention. |
| SUPERSEDED | Earlier result invalidated by a corrected model/implementation. |
| HISTORICAL CERTIFICATION EXCEPTION | Frozen predecessor claim remains authoritative, but original implementation/certificate convention is not fully reconstructible. |
