# 6. Universal game-graph core
## 6.1 Strict attractor
For a finite turn-based game graph and exact target T, Attr(T) is the least fixed point containing T and closed under attacker-existential and defender-universal predecessors, with shortcut semantics fixed in the object domain. This operation is topology-independent once the graph and terminal contract are fixed.
## 6.2 Branch-Kernel Factorization
Let A1=Attr(T1), A2=Attr(T2), B=A1∪A2 and P=Attr(T1∪T2)\B. A branch-kernel state is a residual defender node whose legal replies all enter B while the reply set is not wholly contained in A1 or wholly contained in A2. The strict pure bridge P is exactly the residual backward closure generated by that kernel. Consequently, a strict pure bridge exists if and only if the branch kernel is nonempty.
Proof idea: choose a minimum union-attractor-rank state in a nonempty pure region. It cannot be attacker-owned without either entering a constituent attractor or contradicting minimum rank. It is therefore defender-owned; all lower-rank successors lie in the constituent union, while non-membership in either constituent forces the replies to span alternatives. The converse is immediate, and induction on union rank gives the full closure.
Corollary: constituent-attractor subsumption is sufficient for zero pure BRIDGE. This explains the rook zero-bridge families where the safe-inheritance attractor already subsumed the target attractor.
## 6.3 Hyperkernel Factorization
The same minimum-rank argument extends to finite n-way target unions. The region that can force the full union but no proper subunion is generated by residual defender hyperkernel states whose replies collectively require more than any proper-subunion basin. G6 machine-certified the three-way case across the N/B/R atlas.
Independent regression: a separate implementation checked 100,000 arbitrary finite turn-based total game graphs with zero two-target and zero three-target factorization mismatches. This supports implementation generality but is not substituted for the proof argument above.

# 12. Terminal semantics is part of the proof type
The wrong-colour bishop rook-pawn fortress gives the decisive exact counterfactual. Under faithful promotion continuation the arena contains 1,182,440 states = 825,269 White wins + 357,171 draws, and BK=a8 implies draw for all 22,008/22,008 states. Replacing faithful continuation with the historical “promotion is immediate White win” shortcut adds 274,296 false White wins in this topology.
Therefore terminal semantics cannot be treated as an implementation note. It must be a mandatory field of every proof object’s domain. A proof object transferred between different terminal models requires re-certification.
The faithful fortress also establishes a role-dual compositional object: from the 22,008-state direct corner sanctuary, Black’s strict defender attractor certifies 228,737 draw states, or 64.0413% of the entire draw basin, with zero White wins.
